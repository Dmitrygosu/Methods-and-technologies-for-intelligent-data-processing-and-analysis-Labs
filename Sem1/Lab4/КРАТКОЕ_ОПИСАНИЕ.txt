                    КРАТКОЕ ОПИСАНИЕ ЧЕТВЕРТОЙ ЛАБОРАТОРНОЙ

ЧТО ДЕЛАЕТ КОД:
---------------
Программа сравнивает эффективность различных алгоритмов кластеризации машинного
обучения для задачи группировки объектов по схожести без знания правильных
ответов:

- Группирует клиентов интернет-магазина по схожести характеристик поведения
- Использует 4 типа кластеризаторов: K-Means (метод k-средних), DBSCAN
  (плотностная кластеризация), иерархическая кластеризация, гауссова смесь
  распределений (Gaussian Mixture Model)
- Для каждого кластеризатора тестирует различные комбинации параметров
- Сравнивает качество группировки и время выполнения

КАКУЮ ПРОБЛЕМУ РЕШАЕТ:
---------------------
Проблема: В задачах кластеризационного анализа необходимо выбрать оптимальный
алгоритм и его параметры для группировки объектов по схожести. Разные алгоритмы
кластеризации работают по-разному в зависимости от структуры данных, наличия
шума, формы кластеров и других характеристик.

Решение: Программа автоматически:
- Тестирует множество комбинаций кластеризаторов и их параметров
- Сравнивает модели по метрикам качества (индекс силуэта, индекс
  Калинского-Харабаша, индекс Дэвиса-Болдуина) и скорости
- Визуализирует результаты для понимания компромисса между качеством и временем
- Позволяет выявить лучший алгоритм для конкретной задачи сегментации клиентов

ЗАЧЕМ ЭТО НУЖЕО:
---------------
1. ПРАКТИЧЕСКАЯ ПОЛЬЗА:
   - Помогает выбрать оптимальный кластеризатор для задачи сегментации клиентов
   - Демонстрирует влияние параметров на качество кластеризации
   - Показывает компромисс между точностью группировки и вычислительными
     затратами
   - Обучает пониманию сильных и слабых сторон различных подходов к кластеризации

2. ОБРАЗОВАТЕЛЬНАЯ ЦЕННОСТЬ:
   - Демонстрирует работу различных алгоритмов кластеризации
   - Показывает методы оценки качества кластеризационных моделей
   - Визуализирует результаты для лучшего понимания различий между алгоритмами
   - Иллюстрирует влияние параметров на результаты кластеризации

СУТЬ ЭКСПЕРИМЕНТА:
----------------

ДАННЫЕ:
- Датасет о клиентах интернет-магазина (200 клиентов, 4 признака: возраст,
  средний чек, частота покупок, время на сайте)
- Нормализация признаков методом min-max для одинакового масштаба

ЭКСПЕРИМЕНТ: КЛАСТЕРИЗАЦИЯ
--------------------------
Для каждого кластеризатора:
1. Обучается модель на данных
2. Выполняется группировка объектов на кластеры
3. Оценивается качество группировки с помощью метрик
4. Измеряется время выполнения (обучение + группировка)

Параметры для каждого типа кластеризатора:
- K-Means: количество кластеров k = 2, 3, 4, 5; максимальное число итераций =
  100, 200
- DBSCAN: радиус соседства eps = 0.3, 0.5, 0.7; минимальное число точек для
  кластера min_samples = 3, 5
- Иерархическая кластеризация: количество кластеров k = 2, 3, 4
- Гауссова смесь: количество компонентов = 2, 3, 4; максимальное число итераций
  = 50, 100

Каждая конфигурация запускается 5 раз с разными случайными начальными значениями
для оценки стабильности результатов.

Результат: Определяется лучший кластеризатор по качеству группировки, а также
анализируется компромисс между качеством и временем выполнения.

РЕЗУЛЬТАТЫ:
----------
Программа генерирует:
1. JSON-файл с подробными результатами всех экспериментов
2. График сравнения индекса силуэта
3. График сравнения индекса Калинского-Харабаша
4. График сравнения индекса Дэвиса-Болдуина
5. График общего сравнения качества кластеризации

Все графики содержат названия на русском языке и показывают результаты
сравнительного анализа различных кластеризаторов.

ВЫВОДЫ ОПИСАННЫЕ В ОТЧЁТЕ:
------
- Какой алгоритм кластеризации лучше работает на данном датасете
- Какие параметры оптимальны для каждого типа кластеризатора
- Какой алгоритм обеспечивает лучший компромисс между качеством и скоростью
- Как влияет выбор параметров на качество кластеризации
- Как количество кластеров влияет на качество для методов с фиксированным
  числом кластеров
- Какие модели лучше справляются с различными структурами данных

СТРУКТУРА КОДА:
--------------
- data/          - работа с данными (загрузка датасета о клиентах,
                  нормализация признаков)
- clusterers/    - реализация кластеризаторов:
                  * kmeans.go - метод k-средних (K-Means)
                  * dbscan.go - плотностная кластеризация (DBSCAN)
                  * hierarchical.go - иерархическая кластеризация
                  * gaussian_mixture.go - гауссова смесь распределений
- metrics/       - вычисление метрик качества кластеризации (индекс силуэта,
                  индекс Калинского-Харабаша, индекс Дэвиса-Болдуина)
- experiment/    - организация экспериментов (сетка параметров, запуск
                  различных конфигураций, сбор статистики)
- utils/         - визуализация результатов (графики сравнения моделей,
                  сравнение метрик)
- main.go        - точка входа, запуск экспериментов и генерация графиков
- Makefile       - автоматизация сборки и запуска

ОСОБЕННОСТИ РЕАЛИЗАЦИИ:
---------------------
- Все алгоритмы реализованы с нуля без использования готовых библиотек машинного
  обучения
- K-Means использует случайную инициализацию центроидов и итеративное
  обновление до сходимости
- DBSCAN реализует алгоритм плотностной кластеризации с возможностью выделения
  выбросов
- Иерархическая кластеризация использует метод полной связки (complete linkage)
  для построения иерархии
- Гауссова смесь использует алгоритм максимизации ожидания (EM) для оценки
  параметров распределений
- Все метрики вычисляются вручную для понимания их сути
- Визуализация выполнена с использованием библиотеки gonum/plot
