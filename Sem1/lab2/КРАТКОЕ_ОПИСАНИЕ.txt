ЧТО ДЕЛАЕТ КОД:
---------------
Программа сравнивает эффективность различных алгоритмов машинного обучения
для решения двух задач:

1. КЛАССИФИКАЦИЯ (с учителем):
   - Определяет, к какому классу (виду ириса) относится цветок
   - Использует 4 классификатора: KNN, Naive Bayes, Decision Tree, 
     Logistic Regression
   - Для каждого классификатора тестирует разные параметры

2. КЛАСТЕРИЗАЦИЯ (без учителя):
   - Группирует цветки по схожести без знания правильных ответов
   - Использует алгоритм K-Means
   - Тестирует разное количество кластеров (2, 3, 4)

КАКУЮ ПРОБЛЕМУ РЕШАЕТ:
---------------------
Проблема: В реальных задачах машинного обучения нужно выбрать оптимальный
алгоритм и его параметры. Разные алгоритмы работают по-разному на разных
данных.

Решение: Программа автоматически:
- Тестирует множество комбинаций алгоритмов и параметров
- Сравнивает их по точности и скорости работы
- Визуализирует результаты для понимания, какой алгоритм лучше

ЗАЧЕМ ЭТО НУЖНО:
---------------
1. ПРАКТИЧЕСКАЯ ПОЛЬЗА:
   - Помогает выбрать лучший алгоритм для конкретной задачи
   - Показывает компромисс между точностью и скоростью
   - Обучает пониманию сильных и слабых сторон алгоритмов

2. ОБРАЗОВАТЕЛЬНАЯ ЦЕННОСТЬ:
   - Демонстрирует работу классификации и кластеризации
   - Показывает, как оценивать качество моделей
   - Визуализирует результаты для лучшего понимания

СУТЬ ЭКСПЕРИМЕНТА:
-----------------

ДАННЫЕ:
- Датасет Iris (150 цветков ириса, 4 признака, 3 вида)
- Разделение: 80% обучение, 20% тестирование
- Нормализация признаков для одинакового масштаба

ЭКСПЕРИМЕНТ 1: КЛАССИФИКАЦИЯ
---------------------------
Для каждого классификатора:
1. Обучаю модель на тренировочных данных
2. Предсказываю классы для тестовых данных
3. Сравниваю предсказания с правильными ответами
4. Вычисляю метрики: точность, F1-score, матрица ошибок
5. Измеряю время выполнения

Параметры:
- KNN: k = 3, 5, 7
- Naive Bayes: без параметров
- Decision Tree: глубина = 5, 10, 15
- Logistic Regression: скорость обучения = 0.01, 0.1; итерации = 100, 500

Результат: Находим лучший классификатор по точности и скорости.

ЭКСПЕРИМЕНТ 2: КЛАСТЕРИЗАЦИЯ
---------------------------
Для K-Means:
1. Задаем количество кластеров (k = 2, 3, 4)
2. Группируем данные без знания правильных ответов
3. Оцениваем качество с помощью Silhouette Score
4. Измеряем время выполнения

Результат: Определяем оптимальное количество кластеров.

РЕЗУЛЬТАТЫ:
----------
Программа генерирует:
1. JSON-файл с результатами всех экспериментов
2. Графики сравнения классификаторов
3. Графики качества кластеризации
4. Графики компромисса точность/время
5. Матрицы ошибок для каждого классификатора

ВЫВОДЫ:
------
- Какой алгоритм лучше работает на данном датасете
- Какие параметры оптимальны
- Какой алгоритм быстрее
- Где алгоритмы ошибаются (из матрицы ошибок)

СТРУКТУРА КОДА:
--------------
- data/          - работа с данными (загрузка, нормализация)
- classifiers/   - реализация классификаторов (KNN, Naive Bayes, 
                   Decision Tree, Logistic Regression)
- clusterers/    - реализация кластеризации (K-Means)
- metrics/       - вычисление метрик качества
- experiment/    - организация экспериментов
- utils/         - визуализация результатов
