================================================================================
                    КРАТКОЕ ОПИСАНИЕ ТРЕТЬЕЙ ЛАБОРАТОРНОЙ 
        (НА СЛУЧАЙ ЕСЛИ В ОТЧЁТ ПОКАЖЕТСЯ НАГРАМОЖДЁННЫМ)
================================================================================

ЧТО ДЕЛАЕТ КОД:
---------------
Программа сравнивает эффективность различных алгоритмов регрессии машинного 
обучения для задачи прогнозирования непрерывных значений:

1. РЕГРЕССИЯ (с учителем):
   - Предсказывает цену квартиры на основе признаков (площадь, комнаты, этаж, 
     возраст дома)
   - Использует 6 типов регрессоров: линейная регрессия (Linear), ридж-регрессия 
     (Ridge), лассо-регрессия (Lasso), дерево решений (Decision Tree), случайный 
     лес (Random Forest), градиентный бустинг (Gradient Boosting)
   - Для каждого регрессора тестирует различные комбинации параметров
   - Сравнивает качество предсказаний и время выполнения

КАКУЮ ПРОБЛЕМУ РЕШАЕТ:
---------------------
Проблема: В задачах регрессионного анализа необходимо выбрать оптимальный 
алгоритм и его параметры для предсказания непрерывных значений. Разные 
алгоритмы регрессии работают по-разному в зависимости от структуры данных, 
наличия нелинейных зависимостей и взаимодействий между признаками.

Решение: Программа автоматически:
- Тестирует множество комбинаций регрессоров и их параметров
- Сравнивает модели по метрикам качества (коэффициент детерминации R², 
  среднеквадратичная ошибка RMSE, средняя абсолютная ошибка MAE, средняя 
  абсолютная процентная ошибка MAPE) и скорости
- Визуализирует результаты для понимания компромисса между точностью и временем
- Позволяет выявить лучший алгоритм для конкретной задачи прогнозирования цен

ЗАЧЕМ ЭТО НУЖНО:
---------------
1. ПРАКТИЧЕСКАЯ ПОЛЬЗА:
   - Помогает выбрать оптимальный регрессор для задачи прогнозирования цен
   - Демонстрирует влияние параметров на качество модели
   - Показывает компромисс между точностью предсказаний и вычислительными 
     затратами
   - Обучает пониманию сильных и слабых сторон различных подходов к регрессии

2. ОБРАЗОВАТЕЛЬНАЯ ЦЕННОСТЬ:
   - Демонстрирует работу различных алгоритмов регрессии
   - Показывает методы оценки качества регрессионных моделей
   - Визуализирует результаты для лучшего понимания различий между алгоритмами
   - Иллюстрирует влияние регуляризации и параметров ансамблевых методов

СУТЬ ЭКСПЕРИМЕНТА:
----------------

ДАННЫЕ:
- Датасет о недвижимости (150 квартир, 4 признака: площадь, количество комнат, 
  этаж, возраст дома)
- Целевая переменная: цена квартиры (тыс. руб.)
- Разделение: 80% обучение (120 экземпляров), 20% тестирование (30 экземпляров)
- Нормализация признаков методом min-max для одинакового масштаба

ЭКСПЕРИМЕНТ: РЕГРЕССИЯ
---------------------
Для каждого регрессора:
1. Обучается модель на тренировочных данных
2. Выполняются предсказания для тестовых данных
3. Сравниваются предсказания с истинными значениями цен
4. Вычисляются метрики: коэффициент детерминации R², среднеквадратичная ошибка 
   RMSE, средняя абсолютная ошибка MAE, средняя абсолютная процентная ошибка MAPE
5. Измеряется время выполнения (обучение + предсказание)

Параметры для каждого типа регрессора:
- Линейная регрессия: без параметров (базовая модель)
- Ридж-регрессия: параметр регуляризации alpha = 0.1, 1.0, 10.0 (регуляризация L2)
- Лассо-регрессия: параметр регуляризации alpha = 0.1, 1.0, 10.0 (регуляризация L1)
- Дерево решений: глубина = 5, 10, 15
- Случайный лес: деревьев = 10, 20, 30; глубина = 5, 10; признаков = 2, 3
- Градиентный бустинг: деревьев = 10, 20, 30; глубина = 3, 5; скорость обучения 
  = 0.01, 0.1

Каждая конфигурация запускается 5 раз с разными случайными начальными значениями 
для оценки стабильности результатов.

Результат: Определяется лучший регрессор по точности предсказаний, а также 
анализируется компромисс между качеством и временем выполнения.

РЕЗУЛЬТАТЫ:
----------
Программа генерирует:
1. JSON-файл с подробными результатами всех экспериментов
2. График сравнения коэффициента детерминации R²
3. График сравнения среднеквадратичной ошибки RMSE
4. График компромисса качество/время

Все графики содержат названия на русском языке и показывают результаты 
сравнительного анализа различных регрессоров.

ВЫВОДЫ ОПИСАННЫЕ В ОТЧЁТЕ:
------
- Какой алгоритм регрессии лучше работает на данном датасете
- Какие параметры оптимальны для каждого типа регрессора
- Какой алгоритм обеспечивает лучший компромисс между точностью и скоростью
- Как влияет регуляризация на качество линейных моделей
- Как количество деревьев и их глубина влияют на ансамблевые методы
- Какие модели лучше справляются с нелинейными зависимостями

СТРУКТУРА КОДА:
--------------
- data/          - работа с данными (загрузка датасета о недвижимости, 
                  нормализация признаков, разделение на обучающую и тестовую 
                  выборки)
- regressors/    - реализация регрессоров:
                  * linear.go - линейная регрессия, ридж-регрессия, лассо-регрессия
                  * decision_tree.go - дерево решений для регрессии
                  * random_forest.go - случайный лес для регрессии
                  * gradient_boosting.go - градиентный бустинг для регрессии
- metrics/       - вычисление метрик качества регрессии (коэффициент детерминации 
                  R², среднеквадратичная ошибка RMSE, средняя абсолютная ошибка MAE, 
                  средняя абсолютная процентная ошибка MAPE)
- experiment/    - организация экспериментов (сетка параметров, запуск 
                  различных конфигураций, сбор статистики)
- utils/         - визуализация результатов (графики сравнения моделей, 
                  компромисс качество/время)
- main.go        - точка входа, запуск экспериментов и генерация графиков
- Makefile       - автоматизация сборки и запуска

ОСОБЕННОСТИ РЕАЛИЗАЦИИ:
---------------------
- Все алгоритмы реализованы с нуля без использования готовых библиотек машинного 
  обучения
- Линейные модели используют градиентный спуск для оптимизации
- Деревья решений строятся рекурсивно с критерием минимизации дисперсии
- Случайный лес использует бутстреп-выборки и случайные подмножества признаков
- Градиентный бустинг последовательно обучает деревья на остатках предыдущих моделей
- Все метрики вычисляются вручную для понимания их сути
- Визуализация выполнена с использованием библиотеки gonum/plot
