# Задание 1. Погодный советник (вариант Игнатьев Д.С.)

Веб-приложение: прогноз погоды с публичного API (Open-Meteo) передаётся
локальной LLM (Ollama, qwen2.5:3b со специализацией meteo-sovetnik),
модель возвращает структурированный совет — что надеть, брать ли зонт,
индекс комфорта и пара практических советов.

## Подготовка (один раз)

1. Установить Ollama: https://ollama.com/download
2. Собрать модель: `models\build_model.cmd`
3. `pip install -r requirements.txt` (не нужно, если запускать exe)

## Запуск

Проще всего — `start_all.cmd` в корне лабы (папкой выше): сам поднимет
Ollama, запустит советник и откроет браузер.

Вручную:
- Двойной клик `weather_advisor\dist\weather_advisor.exe`,
  открыть http://127.0.0.1:5000
- Или из исходников: `run_weather.cmd`
- Пересобрать exe после правок кода: `make exe` (нужен pyinstaller) —
  без пересборки exe продолжит работать со старой версией кода

Первый запрос после старта Ollama занимает до минуты — модель поднимается
в видеопамять; дальше ответ 5–10 секунд.

## Проверка (автотест)

`weather_advisor\check_advisor.py` прогоняет несколько городов с разной
погодой, сверяет решение модели про зонт с детерминированным правилом
и список одежды на отсутствие мусора; печатает таблицу вида таблицы 2
из отчёта и завершается с ненулевым кодом при расхождении:

```
cd weather_advisor
python check_advisor.py
python check_advisor.py Владивосток Норильск   # свой список городов
```

## Прочее

- Геокодинг и прогноз кешируются в памяти процесса (прогноз — на 5 минут),
  чтобы повторный ввод того же города не бил лишний раз в API.
- Последние города запроса сохраняются в браузере (localStorage) и
  показываются под строкой поиска кликабельными плашками.
