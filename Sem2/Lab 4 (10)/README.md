В каждой папке свой README с запуском. Все задания используют Ollama
с базовой моделью qwen2.5:3b и специализациями из папок models.

## Быстрые команды

Скрипты (двойной клик):

- `start_all.cmd` — запускает всё разом: Ollama, погодный советник (exe),
  ждёт готовности сайта и сам открывает браузер; если работает Docker —
  поднимает и n8n (для заданий 3-4). Есть ярлык на рабочем столе.
- `stop_all.cmd` — закрывает советник, останавливает n8n, выгружает
  модели из видеопамяти (обратный к start_all).
- `llm_off.cmd` — выгрузить модели из видеопамяти (Ollama остаётся);
- `llm_kill.cmd` — полностью вырубить Ollama;
- `llm_on.cmd` — поднять Ollama обратно.

Повторный запуск `start_all.cmd`, когда всё уже поднято, безопасен —
скрипт просто увидит, что сайт/n8n уже отвечают, и ничего не сломает.

Или через make из корня лабы:

```
make models     # собрать все 6 моделей
make start      # то же самое, что start_all.cmd
make stop       # то же самое, что stop_all.cmd
make check      # автопроверка советника (5 городов, таблица + код возврата)
make task1      # погодный советник (http://127.0.0.1:5000)
make task2      # генератор тестов по обеим целям
make task3      # поднять n8n (чат и почта запускаются из редактора)
make n8n-stop   # остановить n8n
make llm-stop   # выгрузить модели из видеопамяти
make llm-kill   # вырубить Ollama целиком
make llm-start  # запустить Ollama
make status     # что запущено и сколько памяти занято
```
