# Воркфлоу для n8n

## Дискуссионный клуб (workflow_debate_club.json)

Чат с тремя «мнениями». Сообщение пользователя последовательно проходит через
три модели: Оптимист хвалит идею, Скептик разбирает её слабые места (видя
реплику Оптимиста), Эксперт подводит итог (видя обоих). Ответы склеиваются
в одно сообщение чата.

Как пользоваться: открыть воркфлоу, нажать Open chat и написать тему,
например «Хочу переписать наш проект с Python на Go». Если воркфлоу
активирован, чат доступен и по публичной ссылке (кнопка на узле триггера).

## Почтовый ассистент (workflow_mail_digest.json)

Две ветки, сходящиеся в один конвейер анализа:

- боевая: Каждый час -> Почта (IMAP) -> Нормализация -> Анализ письма;
- тестовая: Тестовый запуск -> Тестовые письма -> Анализ письма.

Узел «Анализ письма» прогоняет каждое письмо через модель pochta-analitik,
которая возвращает JSON: спам или нет, категория (Срочно / Встречи /
К сведению), выжимка одним предложением и рекомендуемое действие.
«Сборка дайджеста» группирует письма по категориям и пишет markdown-файл
в /data/output (папка n8n/output на хосте).

Тестовая ветка запускается кнопкой Execute workflow — она подставляет
5 заготовленных писем (2 спама, срочное от преподавателя, приглашение
на созвон, рассылка) и не требует настройки ящика.

Для боевой ветки нужно создать credentials типа IMAP у узла «Почта (IMAP)»:
host imap.gmail.com, port 993, SSL, логин — адрес почты, пароль — пароль
приложения Google (создаётся в настройках аккаунта, раздел «Безопасность»,
обычный пароль от ящика не подойдёт). После этого воркфлоу можно активировать —
триггер будет срабатывать каждый час.

Ollama из контейнера доступна по адресу http://host.docker.internal:11434.
