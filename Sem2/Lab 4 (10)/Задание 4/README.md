# Задание 4. Почтовый ассистент в n8n

Раз в час: почта (IMAP) -> локальная LLM (спам-фильтр, категории
Срочно / Встречи / К сведению, выжимка, действие) -> markdown-дайджест
в папку n8n/output. Тестовая ветка с пятью письмами позволяет проверить
конвейер без реального ящика: открыть воркфлоу -> Execute workflow.

Подготовка: `models\build_model.cmd`, затем `run_n8n.cmd` и импортировать
workflow_mail_digest.json.

Подключение реального ящика: в узле «Почта (IMAP)» создать credentials —
host imap.gmail.com, порт 993, SSL, логин — адрес, пароль — пароль
приложения Google (Безопасность -> Двухэтапная аутентификация -> Пароли
приложений). После этого активировать воркфлоу тумблером.

Подробности по узлам — в README_n8n_детали.md.
