# Задание 3. Дискуссионный клуб в n8n

Чат с локальной LLM: сообщение проходит цепочку из трёх моделей-ролей
(Оптимист -> Скептик -> Эксперт), каждая видит реплики предыдущих,
ответы склеиваются в одно сообщение чата.

Подготовка: `models\build_models.cmd`, затем `run_n8n.cmd` и импортировать
workflow_debate_club.json (Workflows -> Import from File).

Использование: открыть воркфлоу -> Open chat -> написать тему обсуждения.
Если воркфлоу активирован, чат доступен по публичной ссылке узла-триггера.
Ollama из контейнера доступна как http://host.docker.internal:11434.
