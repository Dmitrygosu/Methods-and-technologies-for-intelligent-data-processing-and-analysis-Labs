1. Формулировка проблемы
Задача расстановки восьми ферзей на шахматной доске является классическим примером NP-полной задачи, имеющей множество известных решений. Однако при увеличении размерности доски N количество возможных комбинаций растет экспоненциально, что делает наивные алгоритмы непригодными для практического применения. Основная проблема заключается в поиске наиболее эффективного алгоритмического подхода, который бы обеспечивал баланс между скоростью нахождения решения, вычислительной сложностью и устойчивостью к комбинаторному взрыву. В данной работе исследуются детерминированные и стохастические методы, включая современные распределенные подходы.

2. Анализ существующих подходов
В рамках исследования были реализованы и проанализированы следующие классы алгоритмов:
- Переборные методы (Brute Force): Наивный алгоритм, который в данной работе оптимизирован за счет перебора перестановок (исключение горизонтальных атак). Несмотря на это, сложность остается на уровне O(N!), что ведет к резкой деградации производительности.
- Рекурсивный поиск с возвратом (Backtracking): Систематический обход дерева состояний. Этот метод находит первое решение значительно быстрее брутфорса, поскольку отсекает неверные варианты на ранних этапах, однако все равно крайне чувствителен к росту глубины дерева.
- Эвристические методы (Forward Checking): Использование эвристики Min-Conflicts для выбора наиболее перспективной строки в столбце. Это позволяет «направлять» поиск, минимизируя количество откатов.
- Логическая имитация (Greedy Search с рестартами): Алгоритм имитирует попытки человека расставить ферзей «жадным» образом. При попадании в тупиковую ситуацию (локальный минимум) алгоритм сбрасывает состояние и начинает заново со случайной позиции.
- Мультиагентные системы (MAS): Распределенный подход на базе конкурентной модели Go. Каждый ферзь представлен автономным агентом (go-routine), который самостоятельно стремится к бесконфликтному состоянию, обмениваясь информацией через каналы.

3. Описание моделей
- Математическая модель: Доска представляется как вектор X = (x1, x2, ..., xN), где i — номер столбца, а xi — номер строки. Ограничения формализованы как: xi != xj (отсутствие горизонтальных атак) и |xi - xj| != |i - j| (отсутствие диагональных атак) для всех i != j.
- Модель дерева поиска: Используется в рекурсивных методах. Состояние системы описывается узлом графа, а установка фигуры в новый столбец — переходом. Ограничения выступают в роли функций отсечения (pruning).
- Мультиагентная модель: Децентрализованная система из N агентов. Поведение каждого агента определяется эвристикой локальной минимизации конфликтов. Система считается пришедшей в стабильное состояние (консенсус), когда сумма конфликтов всех агентов равна нулю.

4. Гипотеза
Предполагается, что использование мультиагентного подхода, реализованного на базе конкурентных примитивов языка Go (горутины и каналы), позволит обеспечить лучшую масштабируемость системы на больших размерностях (N > 10) по сравнению с классическими последовательными методами, за счет эффективного распределения вычислений и использования стохастических эвристик.

5. План исследования
1. Проектирование модульной архитектуры на языке Go.
2. Реализация пяти алгоритмов решения (брутфорс, бэктрекинг, эвристика, жадный поиск с рестартами, MAS).
3. Разработка инструментария для проведения автоматических замеров времени выполнения и количества элементарных операций.
4. Проведение численных экспериментов для размерностей N = 8, 10, 12.
5. Визуализация полученных метрик и сравнительный анализ эффективности.

6. План эксперимента
Для оценки эффективности была разработана тестовая среда. Основная цель — выявить момент наступления «комбинаторного взрыва» для каждого метода. Для мультиагентной системы был введен контекст с таймаутом (2 сек.), так как стохастические методы в теории могут зацикливаться. Итерации замерялись как количество попыток перестановки ферзя (для MAS — суммарно по всем агентам). Перед основными замерами проводился «прогрев» рантайма Go для минимизации влияния работы сборщика мусора и планировщика на первых этапах.

Анализ результатов:
При N=8 все алгоритмы находят решение практически мгновенно. Однако уже на N=12 наивный брутфорс продемонстрировал ожидаемый факториальный взрыв, превысив лимит в миллион итераций без нахождения результата. 
Рекурсивные методы (Backtracking и Heuristic) показали стабильно высокую скорость на малых N, что объясняется компактностью дерева поиска для таких размерностей.
Особый интерес представляет мультиагентная система. Хотя на N=8 она показывает большее время из-за накладных расходов на инициализацию горутин, при переходе к N=12 время работы практически не выросло (с 25.8 до 25.1 мс), а количество итераций осталось в рамках статистической погрешности. Это подтверждает масштабируемость метода. Логический подход с рестартами также показал неплохую устойчивость, хотя его время сильно зависит от удачности начального выбора.

8. Вывод
В ходе лабораторной работы было проведено исследование пяти различных подходов к задаче о восьми ферзях. Практика показала, что для малых размерностей вполне достаточно классического рекурсивного поиска. Однако реализация мультиагентной системы (MAS) с использованием конкурентности Go наглядно продемонстрировала преимущество децентрализованных подходов. При реализации MAS основной сложностью стала борьба с потенциальными дедлоками (deadlocks) при обмене сообщениями через каналы, что было решено внедрением неблокирующей логики (default-кейсов в select). Полученные результаты позволяют сделать вывод о высокой эффективности MAS для решения комбинаторных задач большой размерности, за счет замены глобального перебора локальным взаимодействием автономных агентов.
